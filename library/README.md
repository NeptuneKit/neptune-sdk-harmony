# neptune-sdk-harmony

NeptuneKit Harmony SDK (`/v2 only`) for client registration, gateway communication, and local log collection/export.

## Install

Use OHPM to add `neptune-sdk-harmony` in your HarmonyOS project dependencies.

```bash
ohpm install neptunekit-harmony-log
```

or:

```bash
ohpm i neptunekit-harmony-log
```
