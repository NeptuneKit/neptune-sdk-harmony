# 2026-03-25

## Harmony 主动回调模型

- 为 `neptune-sdk-harmony` 新增主动回调模型：`ExportServer` 增加 `POST /v2/client/command`，并默认按 `0.0.0.0` 启动本地 HTTP 服务，保留显式回环地址配置能力。
- 新增 `GatewayClientCallbackManager` 与注册 HTTP 客户端，向网关 `POST /v2/clients:register`，在运行态按 30 秒续约。
- `sessionId` 从来源主键中移除，来源主键收敛为 `platform + appId + deviceId`，`sessionId` 仅保留展示用途。
- demo 侧不再把 WS 作为默认启动主链路；discovery 仍保留，但仅在解析到网关后驱动 callback 注册。
- 新增脚本校验：`node ./scripts/verify-client-callback-contract.mjs`，并更新 `node ./scripts/verify-demo-entry.mjs` 以约束 demo 默认行为。

## Harmony hdc 一键拉起

- 探索确认当前 Harmony simulator / developer mode 下可用的唤醒与输入命令包括 `power-shell wakeup`、`power-shell timeout -o/-r` 和 `uinput swipe`；`aa start -b io.github.neptune.sdk.harmony -a EntryAbility -W` 在当前模拟器上可成功拉起并在 `aa dump -l EntryAbility` 中看到 `state #FOREGROUND`。
- 新增 `scripts/start-demo-via-hdc.sh`，会自动检测 target、寻找或构建 `entry` HAP、尽力执行唤醒/解锁、安装 HAP、启动 `EntryAbility`，并在失败时打印最短人工步骤后等待确认重试。
- README 与 `docs-linhay/dev/2026-03-24-harmony-demo-entry-app.md` 已同步补充一键拉起流程和手工兜底步骤。

## 备注

- 这次改动只触碰 `neptune-sdk-harmony` 仓库本身，没有回滚任何现有未提交改动。
- 后续如果网关侧需要真实可达地址，`GatewayClientCallbackManager` 已预留 `advertisedHost` 配置位。
