# 2026-03-27

- 统一 `neptune-sdk-harmony` 的 ViewTree typography 输出单位为 `dp`，并新增显式单位字段 `style.typographyUnit = 'dp'`。
- 继续补齐源语义字段，便于前端既能统一渲染也能保留真实来源：
  - `sourceTypographyUnit` 保留原始单位语义，按 `vp/fp/px` 输出。
  - `platformFontScale` 输出当前环境字体缩放值，复用现有 `fontSizeScale` 监听。
  - `fontWeightRaw` 保留原始 `attrs.fontWeight` 文本。
- 字段覆盖范围：
  - `fontSize` 按 `vp -> dp` 归一化，默认保持数值不变。
  - `lineHeight`、`letterSpacing` 按 `fp -> dp` 归一化，使用当前 `fontSizeScale` 进行折算。
  - inspector 原始 payload 也同步注入归一化后的 typography 数值、`typographyUnit` 以及源语义字段。
