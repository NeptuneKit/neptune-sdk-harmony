# 2026-04-02

## neptune-sdk-harmony 接入 harmony-log 并改造日志上报

- 决策：`library` 模块新增 `harmony-log` 依赖，并在 SDK 内新增统一日志适配层 `src/main/ets/logging/NeptuneHarmonyLogger.ets`。
- 决策：回调注册、回调管理、WS 管理、Demo 的日志上报 HTTP 客户端全部从 `console.*` 切到 `harmony-log`，并统一补充 metadata（`endpoint`、`statusCode`、`reason`、`callback`、`error`、`bodyText`）。
- 约束：不改动 `/v2/logs:ingest`、`/v2/ui-tree/inspector`、`/v2/clients:register` 契约，仅改日志实现。
- 验证：新增 `scripts/verify-harmony-log-integration.mjs`，先红后绿，确保依赖、导出与日志调用链路落地。

## 日志页客户端路由对齐（alpha）

- 决策：`DemoRuntime` 自动上报日志身份由 `sim-session-discovery/sim-device-discovery` 调整为 `sim-session-alpha/sim-device-alpha`。
- 目的：让 H5 `clients/<platform,appId,sessionId,deviceId>/logs` 路由与自动上报身份一致，避免日志页空白。
- 验证：更新后通过 `GET /v2/logs?platform=harmony&appId=io.github.neptune.sdk.harmony.demo&sessionId=sim-session-alpha&deviceId=sim-device-alpha` 可直接查到新日志记录。

## Demo 新增随机单条日志上报按钮

- 决策：在 `entry` Demo 页新增 `随机上报日志` 按钮，每次点击只上报 1 条随机日志，供三端实时联调快速验证链路。
- 实现：`Index.ets` 新增 `onRandomIngestTap`，`DemoRuntime.ets` 新增 `ingestRandomLogToGateway()`，日志身份固定为 `sim-session-alpha/sim-device-alpha`，并复用当前可用网关端点。
- 验证：`scripts/verify-demo-entry.mjs` 新增按钮与运行时断言，并通过；`scripts/verify-harmony-log-integration.mjs` 继续通过。
