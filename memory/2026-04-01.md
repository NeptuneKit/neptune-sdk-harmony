# 2026-04-01

- discovery 失败的关键修复点是 host 可达性策略，不是单纯的 mDNS 超时。
- 发现 payload 如果返回 `0.0.0.0` / `::` 这类 wildcard host，必须回落到候选 host；不能继续把 wildcard 当作可连接地址。
- loopback host 仍然可以保留，但前提是候选 host 也不提供更明确的可达地址。
- `GatewayDiscoveryResolver` 与 `scripts/verify-gateway-discovery.mjs` 需要保持同一套 reachable-host 规则，避免脚本验证和 ArkTS 实现分叉。
- 最小可执行验证：`node neptune-sdk-harmony/scripts/verify-gateway-discovery.mjs`
